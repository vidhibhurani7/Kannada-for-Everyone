# Kannada for Everyone 🇮🇳

**Kannada for Everyone** is an interactive, beginner-friendly website created for the **Kannada Digital Innovation Hackathon 2026**. It helps people who do not speak Kannada learn practical Kannada words, phrases, and everyday conversations with the support of English meanings and pronunciation guides.

## 🎯 Problem Statement

People who do not speak Kannada may find it difficult to communicate in everyday situations. Beginners may also struggle to understand Kannada vocabulary, pronunciation, and common expressions.

**Kannada for Everyone** aims to make learning Kannada easier and more accessible through an interactive website that combines vocabulary, practical conversations, and guided practice.

## ✨ Features

- **Kannada Vocabulary:** Learn useful Kannada words with Kannada script, Romanized transliteration, and English meanings.
- **Search Functionality:** Find vocabulary quickly using the search feature.
- **Category Filters:** Explore words according to different categories.
- **Pronunciation Support:** Use browser-based text-to-speech when supported by your device and browser.
- **Everyday Conversations:** Explore useful conversations for greetings, shopping, and asking for directions.
- **Situation-Based Phrases:** Discover practical Kannada expressions for everyday situations.
- **Interactive Quiz:** Test your knowledge with a five-question vocabulary quiz.
- **Learning Progress:** Save your progress and best quiz score in your browser.
- **Responsive Design:** Use the website on desktop computers, laptops, and mobile devices.

## 🛠️ Technology Stack

The project is built using the following technologies:

- **HTML5** — Structures the website content.
- **CSS3** — Provides styling, layout, and responsive design.
- **JavaScript** — Adds interactive features and functionality.
- **Web Speech API** — Provides browser-based speech playback where supported.
- **Browser Local Storage** — Saves learning progress and the best quiz score on the user's device.

No Python or paid API is required.

## 🚀 Run Locally

To run the website on your computer:

1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Explore the website and try its available features.

You can also open the project in Visual Studio Code and use the **Live Server** extension to run it locally.

An internet connection is only needed for optional Google Fonts if they are loaded from the online service.

## 🌐 Deployment

The website can be hosted using **GitHub Pages**.

### Deployment Steps

1. Upload the project files to a GitHub repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and the `/ (root)` folder.
6. Click **Save**.
7. Wait for deployment and open the published website link.

## 🎓 Project Purpose

The purpose of Kannada for Everyone is to support beginners in learning practical Kannada through an accessible and interactive digital platform.

By combining Kannada vocabulary, English meanings, pronunciation guides, everyday conversations, and quizzes, the website provides a simple starting point for learning Kannada for daily communication.
